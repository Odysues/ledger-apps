# Ledger Apps

Two installable bookkeeping web apps (PWAs):

- `company/` – company ledger: properties, tenancies, loans, invoices, VAT, profit & loss
- `sole-trader/` – sole trader ledger: drawings, invoices, mileage, Self Assessment tax estimate

Both run entirely in the browser. Data is stored in that browser only (localStorage and IndexedDB) and is never sent to this site. Use Settings → Export All Data to back up and Import Data to restore.

Hosted with GitHub Pages from the `main` branch root.
